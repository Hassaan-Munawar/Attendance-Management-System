Setup Instructions

  1. Create a project at supabase.com
  2. Go to SQL Editor in your Supabase dashboard
  3. Run the included schema.sql to create tables
  4. Copy your Project URL and Anon Key from Project Settings -> API
  5. Paste them on the left and click Save & Connect

Schema file: supabase/schema.sql

All data is retrieved live and stored directly in your Supabase database.
